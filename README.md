# atuf-core

This repository contains the core assets that define the Atuf Linux experience:

- Branding
  - Wallpapers, icons and theme configuration.
- Configs
  - Default KDE Plasma settings, shell profiles and system tweaks.
- Utilities
  - Source code for tools designed to ehance user and developer workflow on Atuf Linux.
